# Code Buddy

Do you code in codeforces? Do you maintain repositories or folders to keep track of all the problems solved by youself in the past? Do you want to visualize your performance in codeforces platform through charts? Then you are in the right place. 

This website allows you to keep track of all the problems you solved in codeforces by saving them and helps you visualize different codeforces stats of your profile.

## Features

To use the features provided by this website, you will have to create an account first.
* You can search any code forces problem present in the codeforces problems section.
* You can make categories/ lists for problems as you like (eg, DP, Tree, Segment Tree, Graph etc.)
* You can save problems in the created categories for later reference.
* You can see your Codeforces profile and visualize the same.
